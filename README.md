# SatarkScan 🛡️
**Scan karo, Satark raho.**

Scam detection and safety app for India.

## Features
- 🔗 Link Scanner
- 📞 Phone Number Checker  
- 💸 UPI ID Checker
- 📸 Screenshot Scanner (OCR)
- 🚨 Scam Reports
- ⚠️ Scam Alerts
- ⚡ Speed Tracker

## Tech Stack
- Flutter (Android)
- Firebase (Auth + Firestore + FCM)
- Google ML Kit (OCR)
- AdMob (Monetization)

## Setup
1. Clone this repo
2. Add `google-services.json` in `android/app/`
3. Run `flutter pub get`
4. Run `flutter run`

## Package Name
`com.satarkscan.app`
